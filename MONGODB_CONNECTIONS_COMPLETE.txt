               COMPLETE MONGODB DATA CONNECTIONS MAPPING
                      Luno Discord Bot Dashboard
================================================================================

DATABASE: lumo-bot
CONNECTION FILES:
  - lib/mongodb.ts (MongoClient for native MongoDB operations)
  - lib/mongoose.ts (Mongoose ODM for schema-based operations)

PRIMARY MODEL:
  - lib/models/ServerSettings.ts (Main schema for all server configurations)

================================================================================
                          API ENDPOINTS & CONNECTIONS
================================================================================

┌─────────────────────────────────────────────────────────────────────────────┐
│                         SERVER MANAGEMENT ENDPOINTS                          │
└─────────────────────────────────────────────────────────────────────────────┘

1. GET /api/servers
   CONNECTION: None (Discord API only)
   PURPOSE: Fetches user's guilds from Discord API
   OPERATIONS: No database operations

2. GET /api/servers/[guildId]/settings
   CONNECTION: ServerSettings.findOne({ guildId })
   PURPOSE: Retrieves server settings, creates default if not exists
   OPERATIONS:
     - READ: ServerSettings.findOne({ guildId })
     - WRITE: new ServerSettings({ guildId }).save() (if not exists)

3. POST /api/servers/[guildId]/settings
   CONNECTION: ServerSettings.findOneAndUpdate({ guildId })
   PURPOSE: Updates server settings
   OPERATIONS:
     - WRITE: ServerSettings.findOneAndUpdate({ guildId }, allowedFields, { upsert: true })

4. GET /api/servers/[guildId]/stats
   CONNECTION: None (Discord API only)
   PURPOSE: Fetches guild statistics from Discord API
   OPERATIONS: No database operations

5. GET /api/servers/[guildId]/channels-and-roles
   CONNECTION: None (Discord API only)
   PURPOSE: Fetches channels and roles from Discord API
   OPERATIONS: No database operations

┌─────────────────────────────────────────────────────────────────────────────┐
│                         GENERAL SETTINGS ENDPOINT                            │
└─────────────────────────────────────────────────────────────────────────────┘

6. GET /api/servers/[guildId]/general
   CONNECTION: ServerSettings.findOne({ guildId })
   PURPOSE: Retrieves general server configuration
   DATA READ:
     - prefix (command prefix)
     - configuration.botNickname
     - configuration.timezone
     - configuration.automod (entire object)
     - configuration.logging (entire object)
   OPERATIONS:
     - READ: ServerSettings.findOne({ guildId })
     - WRITE: ServerSettings.create({ guildId }) (if not exists)

7. PUT /api/servers/[guildId]/general
   CONNECTION: ServerSettings.findOneAndUpdate({ guildId })
   PURPOSE: Updates general server settings
   DATA WRITTEN:
     - prefix
     - configuration.botNickname
     - configuration.timezone
     - configuration.automod.* (all automod settings)
     - configuration.logging.* (all logging settings)
   OPERATIONS:
     - WRITE: ServerSettings.findOneAndUpdate({ guildId }, { $set: updateFields }, { upsert: true })

10. GET /api/servers/[guildId]/modules/[module]
    CONNECTION: ServerSettings.findOne({ guildId })
    PURPOSE: Retrieves specific module configuration and command settings
    MODULES SUPPORTED:
      - moderation, automod, anti-raid (antiRaid), logging, role-management (roleManagement)
      - member-management (memberManagement), announcements, custom-commands (customCommands)
      - fun, utilities, analytics
    DATA READ:
      - modules.{module}.enabled
      - modules.{module}.commands.* (all command configurations)
      - modules.customCommands.command.* (for custom commands module only)
    OPERATIONS:
      - READ: ServerSettings.findOne({ guildId })

11. PUT /api/servers/[guildId]/modules/[module]
    CONNECTION: ServerSettings.findOneAndUpdate({ guildId })
    PURPOSE: Updates specific module and its command configurations
    DATA WRITTEN:
      - modules.{module}.enabled
      - modules.{module}.commands.{commandName}.enabled
      - modules.{module}.commands.{commandName}.allowedChannels
      - modules.{module}.commands.{commandName}.ignoredChannels
      - modules.{module}.commands.{commandName}.allowedRoles
      - modules.{module}.commands.{commandName}.ignoredRoles
      - modules.customCommands.command.* (for custom commands: trigger, title, description, color, footer, thumbnailUrl, imageUrl, fields)
    OPERATIONS:
      - WRITE: ServerSettings.findOneAndUpdate({ guildId }, { $set: updates }, { upsert: true })

└─────────────────────────────────────────────────────────────────────────────┘

22. GET /api/bot-status
    CONNECTION: In-memory storage (No MongoDB)
    PURPOSE: Returns bot online/offline status
    OPERATIONS: No database operations (uses in-memory lastHeartbeat variable)

23. POST /api/bot-status
    CONNECTION: In-memory storage (No MongoDB)
    PURPOSE: Receives heartbeat from bot to update status
    OPERATIONS: No database operations (updates in-memory lastHeartbeat variable)

24. GET /api/bot-stats
    CONNECTION: In-memory storage (No MongoDB)
    PURPOSE: Returns bot statistics (server count, member count, command count)
    OPERATIONS: No database operations (uses in-memory botStats object)

25. POST /api/bot-stats
    CONNECTION: In-memory storage (No MongoDB)
    PURPOSE: Receives statistics updates from bot
    OPERATIONS: No database operations (updates in-memory botStats object)
